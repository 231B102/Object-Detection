# Object-Detection
Image Detection with YOLO & 🗣️ Text-to-Speech

This project combines object detection using YOLO with text-to-speech (TTS) capabilities to create an assistive system that can detect objects in images or video streams and narrate the detected results aloud.

🚧 Status: Work in Progress

📌 Features (Planned & Implemented)

✅ Real-time object detection using YOLO (You Only Look Once)

🔄 Display bounding boxes & class labels on detected objects

🔄 Integration with a Text-to-Speech engine to narrate detected objects

🔄 Support for both image inputs and live webcam/video feeds

🔄 Custom dataset training support (for domain-specific use cases)

🛠️ Tech Stack

Object Detection: YOLO (v5/v7/v8 depending on chosen implementation)

Deep Learning Framework: PyTorch / TensorFlow

Text-to-Speech: pyttsx3 / gTTS / any chosen TTS library

Programming Language: Python

Optional: OpenCV (for video stream handling & visualization)
